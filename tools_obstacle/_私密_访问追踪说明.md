# 隐蔽访问追踪 — 给王迪的私密说明

> ⚠️ 本文件**不会**被 GitHub 推送（已加入 `.gitignore`），仅本地保留。

## 一、它干什么

每个访客打开网页时，自动记录下来：访问时间、IP、浏览器信息、操作了什么（上传文件、计算、导出 XLSX/TXT）。

**所有访客完全无感知** —— 页面上没有任何日志相关的字样。

## 二、看访问记录的两种方式

### 方式 A：飞书机器人实时推送（推荐）

每次有人访问/操作，**手机飞书立刻收到一条消息**，比刷网页方便。

**配置一次（5 分钟）：**

1. 飞书 → 我 → 创建一个**只有你自己的私群**
2. 点群名 → 设置 → 群机器人 → 添加机器人 → **自定义机器人**
3. 给它起名「障碍物访问通知」→ 安全设置随便选一个（关键词最简单，写"障碍物"就行）
4. 拷出 webhook URL（形如 `https://open.feishu.cn/open-apis/bot/v2/hook/xxxxx`）
5. 打开 https://share.streamlit.io → 点击你的 app → ⋮ → Settings → **Secrets**
6. 粘进去：

```toml
TRACKER_TOKEN = "amanda2026"
TRACKER_FEISHU_WEBHOOK = "https://open.feishu.cn/open-apis/bot/v2/hook/你的key"
```

7. 保存 → app 自动重启

**推送内容样例：**
```
🛬 障碍物分析 [visit]
时间: 2026-04-19 21:15:33
会话: a3f9c2b1  IP: 122.225.78.10
UA: Mozilla/5.0 (iPhone; ...)

🛬 障碍物分析 [upload]
时间: 2026-04-19 21:16:02
file=ZBAA_AD_2.pdf size_kb=856.3 method=AIP_PDF icao=ZBAA

🛬 障碍物分析 [export]
fmt=xlsx icao=ZBAA
```

### 方式 B：浏览器打开管理员页（适合详细复盘）

URL 加参数访问（**只有你知道**）：

```
https://你的streamlit域名/?view=__amanda__&token=amanda2026
```

进去后看到：
- 总事件数 / 访问数 / 独立会话 / 独立 IP / 上传&导出次数
- 最近 24 小时活动数
- 完整事件表（时间、事件、会话 ID、IP、语言、UA）
- 一键下载完整 jsonl 日志

**别人不小心访问 `?view=__amanda__` 但没带 token，页面会彻底空白**（`st.stop()`），不会泄露这个功能。

## 三、安全建议

1. **改 token**：`amanda2026` 太好猜了，去 Streamlit Secrets 改成只有你知道的随机串
2. **token 别发到任何聊天**，需要时直接收藏管理员 URL 到浏览器书签
3. 飞书 webhook URL 等同密码，**别贴 GitHub**

## 四、本地查看（不依赖云端）

如果你在本地跑 `streamlit run app.py`，日志默认写到 `/tmp/airport_obstacle_usage.jsonl`。

```bash
# 查最近 20 条
tail -20 /tmp/airport_obstacle_usage.jsonl | python3 -m json.tool --no-ensure-ascii
```

## 五、Streamlit Cloud 重启会清空 /tmp 吗？

会。所以**强烈建议配飞书 webhook**，让历史数据留在飞书消息里。

如果想要永久数据库存储，下一步可以接入 Supabase 免费套餐（100MB 够用 10 年）—— 需要时告诉我。
